# Zor SVG source notes

The wordmark outlines in the two lockups were exported from the repository's
\`apps/mobile/assets/fonts/SpaceGrotesk-SemiBold.ttf\` using \`opentype.js\`.
Space Grotesk is licensed under the SIL Open Font License 1.1. Its license
permits use, modification, embedding, redistribution, and sale when bundled
with software, subject to the OFL terms; the original font name is not used
for this Zor artwork. The source font remains unmodified in this repository.

The Z mark itself is original geometry on a 64-unit grid. All four SVGs use
\`currentColor\`, transparent backgrounds, and no runtime font, text element,
raster image, gradient, filter, or shadow.
